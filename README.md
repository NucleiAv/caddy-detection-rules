# caddy-detection-rules
This repo is a collection of custom rules for caddy web server. It includes rules compatible with Wazuh v4.14.6, Suricata v8.0.5, Snort++ 3.12.2.0. It also includes my testing on Wazuh v5.0 beta2 and other tools.

## Suricata
The readme for caddy suricata rules is [Caddy-Suricata-Readme](https://github.com/NucleiAv/caddy-detection-rules/blob/main/suricata/README.md)

## Wazuh
